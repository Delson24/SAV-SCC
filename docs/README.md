# SAV-SCC — Documentação do Projeto Website

Esta pasta reúne a documentação de estratégia, conteúdo, design, arquitetura, implementação e validação do website da **SAV-SCC, SU, Lda.**

## Como usar esta documentação

1. Ler primeiro `01-briefing-principal.md`.
2. Consultar `02-arquitetura-website.md` para a estrutura das páginas.
3. Seguir `03-direcao-visual.md` para decisões de identidade visual.
4. Usar `04-requisitos-funcionais.md` para comportamentos e conversões.
5. Usar `05-guia-implementacao-antigravity.md` como orientação para os agentes de código.
6. Validar o resultado com `06-testes-e-criterios-aceitacao.md`.
7. Atualizar `07-conteudos-e-pendencias.md` quando forem confirmados dados em falta.

## Princípios do projeto

- O website deve apoiar a aquisição de clientes, e não ser apenas um folheto institucional.
- O foco comercial inicial são pequenas empresas de Maputo e arredores, sem excluir organizações médias ou grandes.
- Os serviços prioritários são contabilidade, fiscalidade e gestão financeira.
- Os principais caminhos de conversão são contacto pelo WhatsApp e marcação de reunião/audiência.
- A identidade deve transmitir rigor, confiança e visão de negócio.
- Não inventar factos, qualificações, testemunhos, resultados, contactos ou relações comerciais não confirmados.

## Estado
