# 06 — Testes e Critérios de Aceitação

## 1. Conteúdo e posicionamento

- [ ] O visitante percebe o que a SAV-SCC faz sem ter de interpretar jargão.
- [ ] Os serviços prioritários estão claros: contabilidade, fiscalidade e gestão financeira.
- [ ] A prioridade comercial é compatível com pequenas empresas sem excluir organizações maiores.
- [ ] A mensagem transmite rigor, confiança e apoio à decisão.
- [ ] Não existem alegações não confirmadas, testemunhos inventados ou promessas absolutas.

## 2. Navegação e conversão

- [ ] Todos os links de navegação funcionam.
- [ ] O CTA do WhatsApp aponta para o número oficial confirmado.
- [ ] A marcação de reunião segue um processo real e compreensível.
- [ ] Formulários, caso existam, validam dados e apresentam estados de sucesso/erro reais.
- [ ] Os contactos são consistentes em todas as páginas.
- [ ] Não existem botões decorativos que pareçam funcionais mas não façam nada.

## 3. Design e responsividade

- [ ] O logótipo mantém as proporções corretas.
- [ ] A paleta e a tipografia são consistentes.
- [ ] O layout funciona em telemóveis, tablets e desktops.
- [ ] Não existe scroll horizontal indesejado.
- [ ] Texto, botões e campos são legíveis e utilizáveis.
- [ ] Os estados de foco e hover são claros.

## 4. Acessibilidade

- [ ] A estrutura de títulos é lógica.
- [ ] As imagens informativas têm texto alternativo.
- [ ] É possível navegar por teclado.
- [ ] Os formulários têm rótulos e mensagens de erro acessíveis.
- [ ] O contraste do texto é adequado.
- [ ] A informação não depende exclusivamente da cor.

## 5. Desempenho e SEO

- [ ] Imagens otimizadas para a web.
- [ ] Não há dependências ou scripts desnecessários.
- [ ] Cada página relevante tem título e descrição adequados.
- [ ] A hierarquia de títulos é coerente.
- [ ] URLs, links e metadados são consistentes.
- [ ] Sitemap e robots.txt são configurados quando aplicável.
- [ ] Não existem erros relevantes na consola ou durante a compilação.

## 6. Segurança e privacidade

- [ ] Nenhuma credencial ou chave privada está exposta.
- [ ] Os formulários não simulam envios.
- [ ] Os dados recolhidos são minimizados e encaminhados corretamente.
- [ ] Integrações externas são verificadas e documentadas.

## 7. Publicação

- [ ] Todos os dados institucionais foram confirmados.
- [ ] Os contactos oficiais foram testados.
- [ ] A SAV-SCC autorizou a divulgação dos clientes/logótipos usados.
- [ ] O website foi revisto em dispositivos reais ou emuladores relevantes.
- [ ] Existe uma estratégia de domínio, alojamento, cópias de segurança e manutenção.
